APPS SCRIPT
1. Buka Google Sheet > Extensions > Apps Script.
2. Gantikan keseluruhan Code.gs dengan fail AppsScript_Takwim_Pintar_2027_SK_Kampung_Tarikan.gs yang dibekalkan berasingan.
3. Run setupTakwimSystem2027().
4. Run resetAdminCredentials2027().
5. Run testConnection2027().
6. Deploy > Manage deployments > Edit > New version > Deploy.
7. Execute as: Me. Who has access: Anyone.

Jika menggunakan deployment yang sama, URL /exec tidak perlu ditukar.
